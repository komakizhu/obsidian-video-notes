# 细粒度视频笔记标准

细粒度笔记的目标是让读者在不重新观看整段视频的情况下，仍能复原讲解的知识结构、关键例子和推理过程。它不是逐句字幕转录，也不是只保留主题的摘要，而是把字幕中的独立语义单元重写成连续、准确、可检索的知识段落。

整理前先沿着 SRT 的时间顺序标出定义、机制、案例、数字、步骤、限制、转折和结论。每个独立单元至少对应一个正文段落；如果一个时间段连续讲了多个案例，应按案例拆分。垃圾邮件过滤、在线广告、自动驾驶、医学影像、制造业缺陷检测、语音识别和情感分析这类并列案例，不能合并成“监督学习可用于多个领域”一句带过。

相邻字幕可以合并，而且应当按照讲解逻辑合并，而不是按照时间点或字符数切开。一个语义单元通常包含 3–6 句完整 prose：先提出观点或案例背景，再补足工作方式、例子、数据、结果和限制。同一个案例的背景、操作、输出和使用意义必须保留在同一段中；只有主题、任务、案例或论证发生变化时才换段。每个语义段落开头单独放一个时间戳，使用该段第一条相关 SRT 的起始时间；段落中间出现新的字幕时间点不代表需要换段，也不要让一个段落跨越多个无关主题。

需要保留的细节包括但不限于：输入与输出的具体含义、分类标签的取值、模型或系统的工作步骤、视频中明确给出的年份和数量、案例中的业务目标、因果关系、适用范围、风险和讲述者的限定语。可以修正字幕断句和明显的语音识别错误，但不能凭常识扩写视频没有说过的结论。

质量检查应从正文反向回到 SRT：按时间顺序抽查每个连续字幕区间，确认其中的独立知识点都能在正文中找到对应表达。重点检查同一案例是否被错误拆开，以及段落是否以“因此、所以、然后、而且、并且、但、不过、这就是、这意味着、如果”等续接词开头；这类情况通常说明前后两段仍属于同一个语义单元。若正文只剩“它可以用于很多场景”“模型经过训练后能够生成内容”一类笼统句子，说明信息压缩过度，需要重新拆分并补回具体内容。段落数量不设固定范围，语义完整性、信息覆盖率和阅读连续性优先于时间戳数量。
